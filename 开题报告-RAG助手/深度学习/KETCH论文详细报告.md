# KETCH论文详细研究报告

**论文标题：** KETCH: A Knowledge-Enhanced Transformer-Based Approach to Suicidal Ideation Detection from Social Media Content

**作者：** Dongsong Zhang, Lina Zhou, Jie Tao, Tingshao Zhu, Guodong (Gordon) Gao

**发表期刊：** Information Systems Research (ISR), 2025, Vol. 36, No. 1, pp. 572–599（UTD24顶刊/FT50顶刊）

**DOI：** https://doi.org/10.1287/isre.2021.0619

---

## 一、研究做了什么事情（一句话概括）

本研究提出了一个叫 **KETCH（Knowledge-Enhanced Transformer-based approach）** 的深度学习框架，**将人类专家构建的自杀意念领域词典以"模型级"的方式融入到RoBERTa Transformer模型中**，从社交媒体帖子文本中自动检测用户是否存在自杀意念（Suicidal Ideation, SI），并通过中英双语数据、帖子/用户双级别、跨问题域（自杀+抑郁）的多维度实验和一项真实世界实地研究，全面验证了方法的有效性、鲁棒性和泛化能力。

---

## 二、研究背景

### 2.1 自杀问题的严峻性

- 根据世界卫生组织（WHO），全球每年超过**70万人**死于自杀
- 自杀是15-29岁人群的**第四大死因**
- 美国**4.8%的成年人**和**11.8%的18-25岁年轻人**曾有过严重自杀念头
- 2022年7月美国启用全国性电话号码**988**作为自杀和危机生命线

### 2.2 自杀行为的四个连续阶段

1. **自杀意念（SI）**：关于自杀的想法、考虑或沉思
2. **自杀计划**：制定可能导致死亡的行动方案
3. **自杀未遂**：非致命的、有死亡意图的自伤行为
4. **自杀完成**：导致死亡

自杀意念是后续所有阶段的**风险因素**，也是最早可以被检测和干预的阶段。

### 2.3 传统检测方法的局限

- 依赖问卷（如PHQ-9、SIQ-JR、SBQ-R）和面对面访谈——**被动**且有时间延迟
- **80%**未接受精神科治疗而死于自杀的患者在被询问时没有报告自杀想法
- 只有**25%**试图自杀的人在未遂前一周访问过心理健康专业人士
- 社会污名导致大多数有SI的人不主动寻求帮助

### 2.4 社交媒体作为检测渠道的可行性

- 有精神障碍的人在社交媒体上花费大量时间，愿意披露情绪
- 社交媒体的**匿名性**减少了对社会污名的恐惧
- 个人语言可以反映其情绪和心理状态——自杀者的文本具有独特特征（更自我聚焦、表达更多心理痛苦）
- Facebook、Twitter/X等平台已部署用户发起的SI监测机制，但面对海量用户内容，**自动化检测**至关重要

## 三、研究Gap（四大研究空白）

| 编号 | 研究空白 | 具体描述 |
|------|---------|---------|
| Gap 1 | **Transformer在SID中研究不足** | 现有SID模型多用传统ML（决策树、逻辑回归）或使用静态嵌入的深度学习（CNN、LSTM），需要劳动密集型特征工程。BERT等Transformer模型虽在NLP中表现优越，但在SID领域仍被低估 |
| Gap 2 | **领域知识被忽视** | 现有模型大多纯数据驱动。少数使用词典的研究也只用了边缘词典（情感词典、LIWC），而非核心自杀意念词典。仅有的几个自杀词典（如Gaur等2019）基于医学术语而非社交媒体语言 |
| Gap 3 | **知识整合粒度不对齐** | 现有方法简单拼接词典和Transformer嵌入。问题在于：词典单位是"术语"（词级），而Transformer默认输出是"句/帖子级"表示，两者粒度不匹配，简单拼接效果有限 |
| Gap 4 | **缺乏跨维度验证** | 很少有研究同时在多种语言、多个平台、帖子和用户双级别上评估SID模型，导致模型鲁棒性和泛化能力存疑 |

## 四、创新点

### 创新点1：面向社交媒体的自杀意念领域词典

- 不同于之前基于医学术语或通用情感的词典，本研究构建了**专门针对社交媒体语言特征**的SI词典
- 中文词典320个术语，英文词典370个术语
- 五步流程：定义领域→专家识别种子术语→优化→自动扩展→修剪
- 多轮专家参与，使用评分者间信度（Krippendorff's alpha=0.82）和多数投票机制确保质量

### 创新点2：模型级知识整合方法（首创）

- 作者提出了知识整合的三层分类框架：数据级→嵌入级→模型级
- 此前的研究只实现了数据级和嵌入级的知识整合
- KETCH**首次实现模型级知识整合**——不是简单拼接词典信息，而是用词典作为"指导"来重新设计Transformer的表示学习过程

### 创新点3：对齐动态嵌入 + 基于词典的增强

- **对齐动态嵌入（Aligned Dynamic Embedding）**：将Transformer从帖子级表示"下钻"到术语级，提取每个词的动态上下文重要性
- **基于词典的增强（Lexicon-based Enhancement）**：计算每个词与SI词典的语义相似度，衡量领域相关性
- **联合框架**：将上下文重要性和领域相关性加权融合（w=0.6），同时考虑"这个词在当前语境中是否重要"和"这个词是否与自杀意念相关"

### 创新点4：多维度严格评估

- 跨语言（中文+英文）
- 跨平台（新浪微博+Reddit）
- 跨级别（帖子级+用户级）
- 跨问题域（自杀意念+抑郁检测）
- 包含真实世界的实地研究

## 五、文献综述（四条线索）

### 线索1：传统临床SID方法

传统方法依赖问卷（PHQ-9等）和面对面访谈。主要问题：（1）被动——需要个体主动寻求帮助；（2）有时间延迟；（3）基于主观自我报告，患者可能隐瞒。

### 线索2：基于社交媒体文本的SID方法演进

| 阶段 | 方法类型 | 代表研究 | 主要局限 |
|------|---------|---------|---------|
| 第一阶段 | 内容分析（关键词过滤、统计语言特征、主题建模） | Huang等(2007)、Varathan和Talib(2014) | 依赖规则匹配，灵活性差 |
| 第二阶段 | 特征工程+传统ML（n-gram、TF-IDF、情感特征+SVM/LR等） | Choudhury等(2016)、Aladağ等(2018) | 特征选择劳动密集且临时性 |
| 第三阶段 | 深度学习（CNN、LSTM、BiLSTM+静态嵌入Word2Vec/GloVe） | Ji等(2019b)、Morales等(2019)、Schoene等(2021) | 使用静态嵌入，无法处理多义词和OOV问题 |
| 第四阶段 | Transformer（BERT、RoBERTa+动态嵌入） | Ji等(2022a)、Haque等(2020) | 直接提取嵌入无增强，未整合领域知识 |

静态词嵌入的三大局限：
1. 同一个词不论上下文都有固定向量表示——无法处理**多义词**
2. 不提供子词级共享表示——形态相似但语义不同的词可能被认为相似
3. 难以处理**词汇表外（OOV）**的词

### 线索3：用户级 vs 帖子级SID模型

| 维度 | 帖子级模型 | 用户级模型 |
|------|-----------|-----------|
| 分析单元 | 单个帖子 | 用户（聚合多条帖子） |
| 目标 | 评估发帖时刻的心理状态 | 预测用户的潜在自杀风险程度 |
| 应用 | 近实时干预 | 风险筛查和评估 |
| 聚合方法 | 不需要 | 拼接法/平均法/集成法 |
| 代表研究 | Huang等(2014)、Tadesse等(2020) | Allen等(2019)、Bitew等(2019) |

### 线索4：将知识整合到深度学习的三层框架

| 层次 | 方法 | 描述 | 复杂度 |
|------|------|------|--------|
| **第1层：数据级** | 预处理/增强/拼接 | 使用知识预处理或增强输入文本 | 低 |
| **第2层：嵌入级** | 拼接/融合/联合优化 | 用知识优化或丰富嵌入向量 | 中 |
| **第3层：模型级** | 模型对齐（本研究首创） | 用知识指导改进模型架构设计 | 高 |

现有SID研究中的词典使用情况：
- 大多使用**边缘词典**（情感词典NRC、LIWC等），仅少数使用核心自杀词典
- 所有已有研究几乎都使用**静态嵌入**
- 知识整合主要停留在**数据级和嵌入级的简单拼接**

## 七、模型架构详解（KETCH四大组件）

### 7.1 整体架构

KETCH包含四个主要组件，形成从输入到输出的完整pipeline：

```
原始社交媒体帖子
    ↓
[组件1] 文本预处理（数据清洗 + 分词）
    ↓
[组件2] 表示优化（嵌入级知识融合）
    │   └─ 用SI标注数据微调RoBERTa
    ↓
[组件3] 表示增强（模型级知识整合）★核心创新★
    │   ├─ 对齐动态嵌入（上下文重要性）
    │   ├─ 基于词典的增强（领域相关性）
    │   └─ 加权融合 → 增强后的帖子表示
    ↓
[组件4] 分类（TPOT自动选择最优分类器）
    ↓
输出：有SI / 无SI
```

### 7.2 组件1：文本预处理

- **数据清洗**：去除噪声、规范化
- **分词**：
  - 中文：将连续字符序列切分为词（因中文无空格分隔）
  - 英文：将标点符号与词分离
- 使用特殊token：`[CLS]`（帖子开头）、`[EOS]`（帖子结尾）、`[SEP]`（句子分隔符）
- 帖子长度标准化：M设为所有帖子的中位长度，长帖截断、短帖填充

### 7.3 组件2：表示优化——通过知识融合微调RoBERTa

**为什么选择RoBERTa（而非BERT）：**
- RoBERTa是BERT的优化版本，采用更大的训练数据和更优的训练策略
- 双向训练（同时看左右上下文）
- 自注意力机制：考虑帖子中所有词的上下文关系，而非简单的词编码平均
- 一次读取整个词序列来预测被遮掩的词
- 在大规模语料上预训练，有效解决OOV问题

**微调过程：**

给定帖子集合C，每个帖子p包含M个token：p = {t₁, t₂, ..., t_M}

帖子表示：v_p = e_CLS ∈ R^h（h=1024维的实值向量）

分类函数：
```
P(y=1|v_p) = softmax(W·v_p)    （公式3）
```

优化函数（负对数似然）：
```
J(X) = -log(P(v_p))            （公式4）
```

通过最小化损失函数J(X)更新权重矩阵W，进而更新RoBERTa模型参数。

**微调超参数：**
| 超参数 | 值 |
|-------|-----|
| 批大小（Batch Size） | 8 |
| 权重衰减（Weight Decay） | 0.1 |
| 最大训练轮次（Max Epochs） | 4 |
| 学习率调度 | 线性衰减 + 预热比0.06 |
| 嵌入维度h | 1024 |

**微调的目的**：预训练的RoBERTa是通用的，微调使其能够捕捉自杀意念文本中的语言细微差别和领域特征。

### 7.4 组件3：表示增强——通过模型对齐（★核心创新★）

这是KETCH最重要的创新组件，包含两个子组件：**对齐动态嵌入**和**基于词典的增强**。

#### 7.4.1 设计动机

两个关键考虑驱动了表示增强的设计：

**考虑1：领域相关性**
帖子中与SI词典术语越相似的词，通常越可能与自杀意念相关。例如，帖子中出现"不想活"这样的词，与词典中的相关术语相似度高，应被赋予更高的重要性。

**考虑2：上下文依赖性**
即使是词典中的术语，在不同上下文中含义也可能不同。例如：
- "杀"是SI词典术语
- 但在"在这所医院，**杀菌**是通过化学过程完成的"中，"杀"完全不涉及自杀意念
- 因此，仅判断一个词是否在词典中是**不够的**，还需要考虑其在当前上下文中的含义

#### 7.4.2 对齐动态嵌入（Aligned Dynamic Embedding）——衡量"上下文重要性"

**核心问题**：标准Transformer模型默认输出帖子级别的表示（通过`[CLS]` token），无法区分同一帖子中不同术语的重要性差异。

**解决方案**：将表示从帖子级"下钻"到术语级。

**具体步骤：**

1. **提取术语级嵌入**：从RoBERTa中提取每个术语t的嵌入向量 v_t = (v¹_t, ..., v^h_t) ∈ R^h

2. **多层注意力提取**：不只使用最后一层，而是提取最后q层（q=4，通过敏感性分析确定最优值）的注意力分数。使用多层的原因是最后几层的表示各向异性（anisotropy）最大化，能更好地捕捉上下文信息。

3. **计算术语级动态注意力**：
```
att(t, p) = Σᵢ₌₁ᵍ Σⱼ₌₁ⁿ aᵢⱼ(t, p) / (q × n)    （公式5）
```
其中：
- aᵢⱼ(t, p) = 术语t在帖子p中，在第i层第j个注意力头上的原始自注意力分数
- q = 最后层数 = 4（实证确定）
- n = 每层注意力头数 = 12（RoBERTa架构固定）
- Q = RoBERTa总层数

**与标准Transformer注意力的关键区别**：
- 标准Transformer：注意力分数在帖子级聚合 → 无法区分不同词的重要性
- 对齐动态嵌入：保留术语级注意力 → 每个词有独立的上下文重要性分数
- 考虑了同一帖子中其他词对当前词的影响 → "动态"

#### 7.4.3 基于词典的增强（Lexicon-based Enhancement）——衡量"领域相关性"

**目标**：利用SI词典来确定帖子中每个术语与自杀意念的相关程度。

**具体步骤：**

1. **术语和词典术语的嵌入对齐**：将帖子术语t和词典术语l都表示在同一嵌入空间R^h中

2. **计算术语-词典相似度**：对于帖子中的术语t和SI词典L：
```
sim(t, L) = max_{l∈L} sim(t, l)    （公式6）
```
- 使用余弦相似度作为相似性度量（最常用的相似度指标之一）
- 取术语t与词典中**最相似**术语的相似度作为t的领域相关性
- 相似度越高 → 该术语与自杀意念越相关

#### 7.4.4 术语重要性的融合计算

将上下文重要性和领域相关性**加权融合**：

```
imp(t, p) = w × sim(t, L) + (1-w) × att(t, p)    （公式7）
```

其中：
- imp(t, p) ∈ (0, 1)：术语t在帖子p中对SI预测的总体重要性
- w ∈ [0, 1]：权重参数，控制领域相关性vs上下文重要性的相对比重
- w = 0.6（最优值，通过敏感性分析确定）
- 含义：**领域相关性（词典）略重于上下文重要性（注意力）**

**重要性的两种极端情况：**
- 当imp(t, p)接近1：该术语与词典高度相似 且/或 在当前上下文中非常重要 → 对帖子表示的影响最大
- 当imp(t, p)接近0：该术语与词典无关 且 在上下文中不重要 → 对帖子表示的影响最小

#### 7.4.5 增强帖子表示的生成

用每个术语的重要性对其嵌入向量进行加权，然后聚合生成增强后的帖子表示：

```
v'_p = (1/M) Σᵢ₌₁ᴹ (imp(tᵢ, p) × v_{tᵢ})    （公式8）
```

其中：
- v_{tᵢ}：术语tᵢ的原始嵌入向量
- M：帖子的最大长度
- v'_p：增强后的帖子表示向量

**设计的精巧之处**：
1. 词典中的术语（如"不想活"）获得高sim值 → 被强调
2. 非词典术语但在上下文中重要的词（如在自杀相关语境中的"累"）仍可通过高att值贡献
3. 词典术语但在非自杀语境中（如"杀菌"中的"杀"）→ att值低 → 被适当弱化
4. 既不是词典术语又不重要的词 → 双重弱化

### 7.5 组件4：分类

**分类任务**：二分类——帖子有SI vs 无SI

**分类器选择——TPOT（Tree-based Pipeline Optimization Tool）：**
- TPOT是一个**自动机器学习（AutoML）工具**
- 使用Scikit-learn库的机器学习算法
- 采用**遗传编程**的随机全局搜索来自动发现：
  - 最佳分类算法
  - 最优超参数组合
  - 最佳模型集成方式
- 输入：增强后的帖子表示 v'_p
- 输出：帖子是否包含SI的预测

**选择TPOT的原因**：大量超参数需要调优，人工调参困难且可能次优。AutoML可以自动化这一过程并保证性能。

### 7.6 用户级模型的扩展

除了帖子级模型，KETCH还被扩展为用户级模型。三种用户帖子聚合方式：

| 聚合方法 | 具体做法 | 最佳适用场景 |
|---------|---------|------------|
| 拼接法 | 按时间顺序拼接用户最近N条帖子的表示向量 | 最常用但非最优 |
| 平均法 | 对用户最近N条帖子的嵌入向量取平均 | **实验证明最优** |
| 集成法 | 对每条帖子独立预测，若任一帖子检测到SI则判定用户有风险 | GPT-ESI词典下最优 |

使用最近1-5条帖子（因77.3%的Reddit用户只有1条帖子，平均1.66条）。

## 八、求解算法与训练策略详解

### 8.1 训练流程概览

```
第一阶段：数据准备
    ├─ 文本预处理（清洗 + 分词）
    ├─ SMOTE过采样平衡训练数据
    └─ 训练集/测试集划分

第二阶段：表示优化（RoBERTa微调）
    ├─ 加载预训练RoBERTa
    ├─ 在SI标注数据上微调（最小化负对数似然损失）
    └─ 更新模型参数

第三阶段：表示增强
    ├─ 提取术语级嵌入和注意力分数（最后4层×12头）
    ├─ 计算对齐动态嵌入 att(t, p)
    ├─ 计算术语-词典相似度 sim(t, L)
    ├─ 计算术语重要性 imp(t, p) = 0.6×sim + 0.4×att
    └─ 生成增强帖子表示 v'_p

第四阶段：分类
    ├─ 使用TPOT自动搜索最优分类器
    ├─ 5折交叉验证 + 30次独立运行
    └─ 输出平均性能
```

### 8.2 数据不平衡处理——SMOTE

**问题**：微博数据集中SI帖子与非SI帖子的比例约为**1:6**，高度不平衡。如果不处理，模型会偏向多数类（非SI），导致大量漏检。

**解决方案——SMOTE（Synthetic Minority Oversampling TEchnique）：**
- 不是简单复制少数类样本，而是通过**合成新的少数类实例**来平衡数据
- 在少数类样本的特征空间中，找到最近邻，在连线上生成新样本
- 生成平衡的训练数据，使模型能公平学习两个类别的特征

### 8.3 超参数设置汇总

| 超参数 | 值 | 确定方式 |
|-------|-----|---------|
| RoBERTa嵌入维度h | 1024 | 遵循Liu等(2019) |
| 微调批大小 | 8 | 实证 |
| 权重衰减 | 0.1 | 实证 |
| 最大训练轮次 | 4 | 实证 |
| 学习率预热比 | 0.06 | 实证 |
| Word2Vec嵌入维度（基线） | 150 | 实证 |
| 注意力层数q | 4 | 敏感性分析（测试n=1,2,3,4） |
| 注意力头数n | 12 | RoBERTa架构固定 |
| 权重w（领域vs上下文） | 0.6 | 敏感性分析（0到1，步长0.1） |
| 交叉验证折数 | 5 | 标准设定 |
| 独立运行次数 | 30 | 确保结果稳定性 |
| SMOTE | 是 | 处理类别不平衡 |

### 8.4 模型评估策略

**评估流程：**
1. 先用训练集进行**5折交叉验证**来优化超参数和选择模型
2. 用训练好的模型在**独立测试集**上评估
3. 执行**30次独立运行**（重复随机子采样验证），报告平均值
4. 进行**重复测量方差分析（ANOVA）** + **Bonferroni多重比较校正**来统计检验模型差异的显著性

### 8.5 评估指标

| 指标 | 定义 | 侧重点 |
|------|------|--------|
| **精确率（Precision）** | 被检测为SI的帖子中真正有SI的比例 | 减少误报 |
| **召回率（Recall）** | 真正有SI的帖子中被正确检测到的比例 | 减少漏检 |
| **F1分数** | 精确率和召回率的调和平均 | 综合衡量 |
| **准确率（Accuracy）** | 所有预测中正确预测的比例 | 整体正确性 |

对于Reddit用户级实验，使用**Flagged F1分数**：将"有风险"（低/中/高）vs"无风险"进行二分类的F1。

### 8.6 12个基线模型详细配置

| 基线模型 | 架构详情 | 嵌入类型 | 是否使用词典 |
|---------|---------|---------|------------|

| **LSTM** | 两层LSTM（128神经元/层）+ 3个Dropout层(0.2) | 静态 | 否 |
| **BiLSTM** | 双向LSTM，与LSTM相同架构 | 静态 | 否 |
| **GRU** | 两层GRU（128神经元/层）+ 3个Dropout层(0.2) | 静态 | 否 |
| **Bi-GRU** | 双向GRU，与GRU相同架构 | 静态 | 否 |
| **RoBERTa (RB)** | RoBERTa + 1个全连接层 + softmax | 动态(帖子级) | 否 |
| **BERT** | BERT + 1个全连接层 + softmax | 动态(帖子级) | 否 |

## 九、结果评估详解

### 9.1 实验1：KETCH vs 12个基线模型（微博数据，帖子级）

#### 9.1.1 基线模型性能对比

| 模型 | 精确率 | 召回率 | F1 | 准确率 |
|------|--------|--------|-----|--------|
| CNN | 0.420 | 0.500 | 0.457 | 0.840 |
| LSTM | 0.512 | 0.642 | 0.514 | 0.858 |
| GRU | 0.509 | 0.609 | 0.509 | 0.850 |
| BiLSTM | 0.656 | 0.636 | 0.637 | 0.858 |
| BiGRU | 0.669 | 0.699 | 0.671 | 0.869 |
| **RoBERTa (RB)** | 0.747 | 0.674 | 0.705 | **0.906** |
| BERT | 0.652 | 0.690 | 0.666 | 0.797 |
| XLM-RoBERTa | 0.656 | 0.674 | 0.671 | 0.840 |
| 基于规则 | 0.210 | **0.965** | 0.345 | 0.415 |
| Open Theory | 0.689 | 0.298 | 0.416 | 0.866 |
| **DeepAtt** | **0.750** | 0.710 | **0.724** | 0.858 |
| ConvSent | 0.682 | 0.402 | 0.506 | 0.875 |

**关键发现：**
1. RB（无词典）在所有基线中综合表现最好（最高准确率0.906，F1第二0.705）
2. RB一致优于BERT和XLM-RoBERTa → **RoBERTa是更好的基础模型选择**
3. 基于规则的模型召回率极高（0.965）但精确率极低（0.210）→ 大量误报
4. 使用词典的基线并未一致优于不使用词典的基线 → **词典类型和整合方式很重要**

#### 9.1.2 KETCH消融实验——逐步增加组件

| 模型配置 | 精确率 | 召回率 | F1 | 准确率 |
|---------|--------|--------|-----|--------|
| RB（基线） | 0.747 [0.020] | 0.674 [0.021] | 0.705 [0.022] | 0.906 [0.025] |
| RB + RR（+表示优化） | 0.753 [0.018] | 0.689 [0.017] | 0.717 [0.018] | 0.910 [0.020] |
| RB + RR + SM（+SMOTE） | 0.728 [0.015] | 0.857 [0.014] | 0.765 [0.016] | 0.893 [0.017] |
| **KETCH（+表示增强）** | **0.826 [0.007]** | **0.881 [0.009]** | **0.868 [0.009]** | **0.935 [0.010]** |

（方括号内为标准差）

**逐步效果分析（重复测量ANOVA + Bonferroni校正）：**

| 组件 | 精确率变化 | 召回率变化 | F1变化 | 准确率变化 | 显著性 |
|------|----------|----------|--------|----------|--------|
| +RR（表示优化） | +0.006 | +0.016 | +0.012 | +0.004 | 全部p<0.001（准确率p<0.01） |
| +SM（SMOTE） | **-0.025** | **+0.167** | +0.048 | **-0.017** | 召回率和F1显著提升(p<0.001)，精确率和准确率略降(p<0.001) |
| +RE（表示增强） | **+0.098** | +0.024 | +0.103 | +0.043 | 全部p<0.001 |

**核心结论：**
1. **表示优化（RR）** 在所有指标上均有统计显著提升 → 微调有效
2. **SMOTE（SM）** 大幅提升召回率（+0.167），但牺牲了精确率（-0.025）→ 典型的精确率-召回率权衡
3. **表示增强（RE，核心创新）** 在所有指标上都有显著提升，特别是精确率（+0.098）和F1（+0.103）→ **词典知识的融入显著改善了检测效果**
4. 最终KETCH的标准差也最小 → **结果更稳定**

## 十、结论

### 10.1 方法论结论
1. **领域知识有效**：将核心SI词典整合到Transformer中可显著提升SID性能
2. **模型级整合优于拼接**：通过模型对齐的知识整合方式，比简单拼接更有效
3. **两种增强互补**：词典增强（领域相关性）和对齐动态嵌入（上下文重要性）缺一不可，最优w=0.6
4. **专家智慧有价值**：专家策划词典 > ChatGPT生成词典 > 通用情感词典

### 10.2 实证结论
1. KETCH在中文微博帖子级SID中，F1达0.868，准确率0.935，**全面超越12个基线模型**
2. KETCH在英文Reddit用户级自杀风险预测中，F1达0.939，**优于4个专用基线模型**
3. KETCH在抑郁检测中也表现优异 → **跨问题域泛化能力强**
4. 实地研究验证了86%的检测准确率和积极的用户感知 → **具备实际部署可行性**

### 10.3 社会经济影响
- 估计KETCH每年可帮助预防约**1,800例**美国自杀死亡
- 带来约**189亿美元**的成本节省
- 66.2%被检测到的用户此前从未接受过心理干预 → 填补了检测和干预的空白
