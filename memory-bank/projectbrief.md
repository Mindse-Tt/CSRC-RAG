# Project Brief

## Purpose

Create a reusable Codex-centered project operating system for this workspace and future workspaces.

The system should reduce repeated explanation, standardize task delivery, and preserve enough project memory that future AI sessions can start from context instead of from zero.

## Problem

The current workflow depends too much on the user spelling out the task decomposition manually in each session. There is no stable requirement-to-execution framework, and project memory is weak unless it is restated in chat.

## Desired Outcome

- Codex can take a vague task and still move through a fixed workflow.
- Project context and stable user preferences live in local memory files.
- The setup can be copied into other projects with minimal changes.
- The system works in a terminal-first environment.

## Success Criteria

- A reusable Codex skill exists for end-to-end delivery.
- A local memory bank exists and can be queried by Codex.
- Important environment and workflow decisions are documented.
- The user can start a session with one short prompt instead of a long explanation.

## Non-Goals

- Fully autonomous unsupervised software delivery without review.
- Hiding all workflow details behind opaque automation.
- Replacing Codex with a separate large framework by default.
