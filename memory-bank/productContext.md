# Product Context

## Primary User

The primary user is a terminal-first Codex user who wants AI help across coding, research, and project operations.

## Main Pain Points

- Re-explaining project context and working style every session.
- No fixed workflow for requirement intake, task decomposition, execution, and validation.
- Memory exists in chat fragments rather than in durable project artifacts.

## User Expectations

- Chinese-first communication.
- Direct, practical execution.
- Clear assumptions.
- Reusable structure that can be copied into other projects.

## Core Use Cases

- Start a new task with minimal prompt overhead.
- Turn vague requests into an executable plan.
- Preserve stable project context across sessions.
- Record completed work and next steps without relying on memory of prior chats.

## Acceptance Signals

- The user can say a short sentence and still get a structured delivery flow.
- Stable preferences are already known from local memory.
- The system produces durable artifacts, not only temporary chat output.
